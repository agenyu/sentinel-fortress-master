## 当前系统架构

```
rsclbag → [4路 HEVC Camera] → NVDEC 解码 → 鱼眼去畸变 → CameraSync 4路同步
                                                              ↓
                                                    YOLOv8n 检测 (TensorRT)
                                                              ↓
                                                    ByteTrack 多目标跟踪
                                                              ↓
                                              ┌───────────────┼───────────────┐
                                              ↓               ↓               ↓
                                    USS 点云聚类融合    LiDAR cluster融合    IMU 振动检测
                                              ↓               ↓               ↓
                                              └───────────────┼───────────────┘
                                                              ↓
                                                    AlertManager 威胁评估
                                                              ↓
                                                    SentryStateMachine
                                              (STANDBY→ACTIVE→WARNING→ALARM)
                                                              ↓
                                                    RSCL Publish + 事件录像
```

## 已完成功能模块

### 1. 感知链路

- **4路鱼眼相机**：FOV195，1920×1536 HEVC，NVDEC 硬解码 + CPU fallback
- **鱼眼去畸变**：JSON 标定文件解析，remap table 预计算
- **4路严格时间戳同步**：tolerance 80ms，timeout 1000ms，max_buffered 30 帧
- **YOLOv8n 检测**：TensorRT 10.x 推理，支持 FP16
- **ByteTrack 跟踪**：多目标关联，track ID 持续

### 2. 多传感器融合

**USS 点云聚类融合：**
- 12 路 USS 点云解析（PDC/MEB）
- 按相机扇区过滤 + 0.25m 邻域聚类
- 贪心唯一分配：每个视觉目标最多匹配一个 USS cluster
- 历史 USS 快照 + closest-time 查找（解决异步时间戳问题）
- 有效距离 ≤1.3m

**LiDAR 4路 cluster-first 融合：**
- 4 路车辆坐标系 LiDAR：front/left/rear/right
- pointStep=16 stride 解析（兼容 ≥12 字节）
- 车辆坐标系投影到相机像素 → voxel 降采样(0.20m) → 欧氏聚类(0.60m)
- 聚类 bbox 与视觉 track bbox IoU/center cost 贪心匹配
- 仅 ORSM 模式使用，哨兵模式禁用 LiDAR

**IMU 振动检测：**
- 严重冲击 2s 锁存
- 斜坡姿态变化误报修复（需当前 XY 平面扰动）

### 3. 威胁评估 (AlertManager)

- 优先级：严重 IMU/锁存 > 视觉目标 + USS/LiDAR 融合距离 > raw USS 近距 fallback > 一般 IMU 振动 fallback
- USS-cluster 融合目标使用 `uss_distance_m` 作为距离估计
- LiDAR-cluster 融合目标使用 `lidar_distance_m` 作为距离估计
- 检测 fallback 机制（无视觉目标时的 USS/IMU 兜底）

### 4. 状态机 (SentryStateMachine)

- 状态：UNAVAILABLE → STANDBY → ACTIVE → WARNING → ALARM
- ODD 条件：钥匙远离、存储空间、电源状态
- 独立 stateTickLoop（不依赖摄像头帧驱动）
- WARNING 同一威胁 3min 超时
- 钥匙靠近在 WARNING/ALARM 回 STANDBY
- 时间戳安全 elapsed 检查（避免短 bag 下溢）

### 5. ORSM 模式（堡垒模式）

- 独立 ORSM 状态机：ODD satisfied → sw_enable → threat detected → warning
- 与哨兵模式互斥路由
- LiDAR 融合仅在 ORSM 模式激活

### 6. 基础设施

- RSCL Publish：Cap'n Proto 序列化，V2.6 l3 messages
- 事件录像：event_id 固定 + 录制完成后回填 video path
- 多车编队角色对齐
- GPU 服务器日志自动清理 cron（每日 23:59）
